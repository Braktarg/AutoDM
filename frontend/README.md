# AutoDM — Frontend

UI de la mesa de rol. Stack: **React 19**, **TanStack Router/Start**, **Vite**, **Tailwind**.

Documentación principal e instalación: [README en la raíz del repo](../README.md).

```powershell
copy .env.example .env
npm install
npm run dev
```

`VITE_API_URL` debe apuntar al backend FastAPI (por defecto `http://127.0.0.1:8000`).
